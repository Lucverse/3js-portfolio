### About Me

Full-stack engineer with expertise in building multi-tenant SaaS products, real-time event-driven systems, AI-powered applications, and interactive 3D web experiences.

- **SaaS Infrastructure & Distributed Systems**  
  Architecting multi-tenant platforms with account-scoped isolation, 6-level hierarchical RBAC, automated Stripe billing, and Inngest event queues.  
  `Next.js` / `Nextra` / `TypeScript` / `Node.js` / `AWS` / `MongoDB` / `Inngest`

- **AI & Intelligent Automations**  
  Building context-aware RAG pipelines, Qdrant vector search engines, custom LLM integrations, and WhatsApp/Slack operations bots.  
  `FastAPI` / `Python` / `Qdrant` / `Cohere` / `OpenAI` / `Vercel AI SDK`

- **3D & Creative Web Engineering**  
  Crafting high-performance WebGL graphics, custom GLSL shader effects, interactive camera controllers, and responsive canvas interfaces.  
  `Three.js` / `React Three Fiber` / `Unity` / `TailwindCSS`
